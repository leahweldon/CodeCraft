# Frontend Leadership and Contributions

**CodeCraft - Software Engineering Project II, Group 18 (2024)**

## Role

I was responsible for leading frontend development and, as the team adapted its structure, leading the styling workstream. The work combined **React implementation**, user-interface planning, coordination with backend and AI/API developers, and sprint management.

## Frontend Engineering

- Worked on the React application's interface and component structure, with particular attention to the main code-submission experience.
- Contributed to text- and file-based input workflows and the frontend integration of server responses.
- Worked on use-case and model selection controls, user guidance and submission-page behaviour.
- Helped refine layouts and styling using CSS and **Material UI**.
- Collaborated with backend and integration contributors to align frontend requests, expected API responses and interaction design.

These items describe areas I **contributed to**, not an assertion that I independently wrote every component involved.

## Team Leadership and Delivery

- Coordinated frontend contributors and held regular check-ins on priorities, blockers and workload.
- Participated in sprint planning, task delegation, reporting and cross-team communication.
- Helped reorganise the frontend work as the project evolved, including a clearer distinction between styling and integration activities.
- Supported testing, issue resolution and preparation for the final project showcase.
